## Как это делалось (для следующих фото)

- Unsplash и Pixabay из облачной среды не работают: Unsplash закрыт проверкой на бота, Pixabay — Cloudflare.
  Pexels: поиск через WebSearch (`pexels ...`, домен pexels.com), картинка напрямую с CDN по номеру фото:
  `https://images.pexels.com/photos/<id>/pexels-photo-<id>.jpeg?auto=compress&cs=tinysrgb&w=2400`.
- Вырезать человека: `pip install "rembg[cpu]"` в venv, модели `u2net_human_seg` (люди, тёмный фон) или
  `isnet-general-use` (предметы, светлый фон) — скачиваются с GitHub при первом запуске.
- Свои фото людей: присылать оригиналы в `assets/`; PNG без фона можно сделать на iPhone/Mac («Скопировать объект»).
