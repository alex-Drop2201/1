# Мастерская постеров и медиа для соцсетей

Репозиторий для постеров, постов, сторис, каруселей и обложек. Общение с пользователем — на русском.

## Вкус пользователя — читать перед любой работой

Алекс ведёт **медиа церкви**: служения, крещение, причастие, проповеди, молодёжь, цитаты из Писания, расписание, гости.
Его вкус разобран в `references/STYLE.md` (9 приёмов, шрифты, палитра, тон текстов, чек-лист) по 72 референсам из
`references/telegram/`; общий вид — `references/overview.jpg`.

**Правило пользователя: делать только по референсам, ничего «из головы».**
- Новый макет по референсу — по скилу `poster-twin` (`.claude/skills/poster-twin/SKILL.md`): там правила, которые заранее
  исключают ошибки, найденные критикой (шрифты, фото, контраст, вырезки, композиция, факты).
- Каждый макет — адаптация одного конкретного референса; номер в имени файла (`ref-047.html`) и в комментарии.
- Повторить: положение блоков (в % от холста — измерить по картинке), сетку, пару шрифтов, кегли, цвета (снять пипеткой
  с референса), обработку и фактуру. Заменить только текст (русский, смысл церкви) и изображение (своё фото или рисунок).
- Отступать только ради безопасных зон сторис и кириллицы — и называть отступление пользователю.
- Не переносить чужие фото, иллюстрации, логотипы и тексты — только устройство макета.
- Если референс держится на фото, а фото нет — не подменять другим приёмом, а попросить фото по `references/SHOTLIST.md`.
- После рендера — проверка скилом `poster-critique` (основа проверки любого макета): сравнение «референс → наш» с сеткой,
  замеры (контраст, зоны, кегли, даты), проверка шрифтов по `fonts.md`. Критичное и заметное исправить до показа,
  отступления от референса назвать пользователю. Общий лист сравнения — как `projects/2026-10-18-twins/export/compare.jpg`.
- Цель — «близнец»: буквальная копия композиции и стиля референса под наш контекст. Где в референсе фото,
  а своего фото нет, — слот `<div class="slot" data-ph=… data-need="что снять">` из `projects/2026-10-18-twins/twin.css|js`:
  размытое цветовое пятно 8×10 px с референса (не сам снимок) и подпись, что снять. Вырезанный человек — `drawBust()`.
  Когда пользователь пришлёт фото: `data-src="assets/фото.jpg"` (или PNG без фона вместо силуэта) — слот подставит его.
- Пока своих фото нет — стоковые с Pexels (поиск, загрузка с CDN, вырезка rembg и источники — в
  `projects/2026-10-18-twins/STOCK.md`). Стоковый человек с именем («Пастор Иван») — только черновик до своего фото.
- Надпись, которая по задумке уходит за край (как в референсе), помечать `data-bleed` — рендер не будет на неё ругаться.
- Образцы работы по правилу — `projects/2026-10-17-by-refs/` и `projects/2026-10-18-twins/`. Не образцы: генеративные
  `projects/2026-10-16-instagram-10/` и вольные варианты `projects/2026-10-17-church-10/`.

## Как устроено

```
brand/brand.css     цвета и шрифты бренда (CSS-переменные), базовые стили .canvas и [data-slide]
brand/logo/         логотипы (SVG/PNG)
fonts/              шрифты Google Fonts (OFL) + fonts.css (генерируется скриптом)
templates/          шаблоны: post.html (4:5), story.html (9:16), carousel.html; превью в templates/export/
projects/           готовые работы: projects/ГГГГ-ММ-ДД-коротко-латиницей/
scripts/render.cjs  HTML → PNG/JPG/PDF через Playwright (Chromium)
scripts/get_font.py скачать шрифт с Google Fonts и пересобрать fonts/fonts.css
.claude/skills/     скилы проекта (canvas-design, poster-twin, poster-critique, poster-canvas)
```

Макет — это HTML-страница: вёрстка на CSS, рендер в картинку скриптом. Пути к общим файлам — от корня репозитория
(`/brand/brand.css`, `/fonts/fonts.css`, `/brand/logo/...`), рендер поднимает локальный сервер, так что они работают из любой папки.

## Порядок работы над заказом

1. Создать папку `projects/ГГГГ-ММ-ДД-slug/`, скопировать подходящий шаблон из `templates/` (или сверстать с нуля, подключив `/brand/brand.css`).
2. Размер задать в `<meta name="size" content="1080x1350">`. Исходники пользователя (фото, логотипы) — в `projects/<папка>/assets/`.
3. Рендер: `node scripts/render.cjs projects/<папка>/post.html` → `projects/<папка>/export/post.png`.
   Флаги: `--format story|post|square|youtube|wide|og|x|a4|a3`, `--size 1200x628`, `--jpg`, `--pdf`, `--scale 2`, `--out <папка>`.
   Карусель: каждый элемент `[data-slide]` сохраняется отдельным файлом `post-01.png`, `post-02.png`, …
4. **Обязательно посмотреть результат самому** (Read на PNG) и прочитать предупреждения скрипта:
   `⚠ текст выходит за край макета`, `⚠ шрифт не загрузился`, `⚠ не загрузилось`, `⚠ ошибка JavaScript на странице`,
   `⚠ нет начертания`, `⚠ шрифт искажён растяжением`, `⚠ рукописный шрифт слишком мелкий`, `⚠ висячее слово`,
   `⚠ день недели не совпадает с датой` — исправить до показа; `ℹ заглушки` — заменить перед публикацией.
   В скриптах макетов не называть глобальные переменные `top`, `name`, `status`, `parent`, `self` — они заняты браузером, скрипт молча падает.
   Затем прогнать скил `poster-critique` (`.claude/skills/poster-critique/SKILL.md`): сравнение с референсом, контраст,
   зоны, кегли, даты, шрифты — и исправить критичное и заметное до показа. Результаты критики пишутся в `tmp/critique/` и не коммитятся.
5. Отправить пользователю через SendUserFile (status `normal`), коротко подписать.
6. Сразу закоммитить и запушить в `main`: `git add projects/<папка> && git commit -m "Постер: <что>" && git push -u origin main`.
   Пользователь разрешил коммитить и пушить готовые работы в `main` без отдельного вопроса.
7. Выложить макет на холст проекта (скил `poster-canvas`, `.claude/skills/poster-canvas/SKILL.md`): там пользователь
   листает «референс | наш», правит текст руками и оставляет комментарии. На «забери правки» — перенести их
   в исходный HTML, перерендерить, проверить и обновить холст.

## Форматы

| Куда | Формат | Размер |
|---|---|---|
| Instagram / Threads / VK, лента (лучший охват) | `post` 4:5 | 1080×1350 |
| Квадрат | `square` 1:1 | 1080×1080 |
| Stories, Reels, TikTok, Shorts, VK Клипы | `story` 9:16 | 1080×1920 |
| Обложка YouTube | `youtube` 16:9 | 1280×720 |
| Telegram-пост, широкий баннер | `wide` 16:9 | 1920×1080 |
| Превью ссылки (OG), Facebook, LinkedIn | `og` | 1200×630 |
| X / Twitter | `x` 16:9 | 1600×900 |
| Печать A4 / A3, 300 dpi | `a4` / `a3` | 2480×3508 / 3508×4961 |

## Правила дизайна

- Сторис: верхние ~250px и нижние ~340px перекрывает интерфейс — текст и кнопки туда не ставить.
- Пост 4:5 в сетке профиля Instagram обрезается до 3:4 — важное держать в центральных ~1010px по ширине.
- Один макет — одна мысль. Заголовок крупный (от 90px на 1080px ширины), основной текст не мельче 32px.
- Контраст текста к фону — не ниже 4.5:1. На фото — затемнение или плашка под текстом.
- Длинные русские слова: проверять переносы и вылеты (скрипт предупреждает). Неразрывный пробел `&nbsp;` между предлогом и словом, `−` (минус) для скидок.
- Генерации изображений нейросетью здесь нет: графику делать на CSS/SVG (градиенты, формы, типографика) или из фото пользователя.
  Чужие фото и иконки — только со свободной лицензией, источник указать в коммите.

## Шрифты (все с кириллицей)

Inter, Manrope, Montserrat, Rubik — текст и универсальные; Unbounded — акцидентный широкий; Oswald и
Fira Sans Extra Condensed (900) — узкие ударные; Playfair Display (+ italic) и Cormorant Garamond (300/500 + italic) — антиква;
Oranienbaum — узкая контрастная антиква; Great Vibes — каллиграфия; Comforter Brush — сухая кисть (только крупно);
Caveat (маркер), Neucha (перо), Amatic SC и Pangolin (печатный от руки) — рукописные.
Какой русский шрифт брать вместо латинского из референса — `.claude/skills/poster-critique/fonts.md`. Образец: `fonts/export/specimen.png`.
Добавить новый: `python3 scripts/get_font.py "Название" 400 700 [--italic]`, затем `node scripts/render.cjs fonts/specimen.html`
обновит образец. Проверять, что у шрифта есть кириллица (видно на образце).

## Скил canvas-design

Установлен в `.claude/skills/canvas-design/` — копия `skills/canvas-design` из github.com/anthropics/skills без изменений.
Применять для художественных постеров и арт-работ: сначала философия дизайна (.md), потом визуал (.png/.pdf).
Как совмещать с этим репозиторием:

- Всё класть в `projects/<папка>/`: `philosophy.md`, исходник макета и `export/`.
- Рисовать через наш HTML-рендер (CSS, SVG, `<canvas>`) — тогда работают проверки вылета текста и шрифтов. Python + Pillow тоже допустим.
- Шрифты скила подключаются строкой `<link rel="stylesheet" href="/fonts/canvas-fonts.css">`; образцы — `fonts/export/canvas-specimen.png`.
- Кириллица есть только у Arsenal SC, Geist Mono, IBM Plex Mono, IBM Plex Serif, JetBrains Mono, Jura, Lora, Pixelify Sans,
  Poiret One, Tektur. Для русского текста брать их или шрифты из `fonts/`; остальные шрифты скила — только для латиницы и цифр.
- Обновить скил: `GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 https://github.com/anthropics/skills <папка>` и скопировать
  `skills/canvas-design` поверх `.claude/skills/canvas-design`.

## Видео и анимация

`ffmpeg` установлен. Простые варианты: слайд-шоу из PNG
(`ffmpeg -framerate 1/3 -i export/post-%02d.png -c:v libx264 -r 30 -pix_fmt yuv420p out.mp4`),
или CSS-анимация, записанная Playwright (`recordVideo`) с последующей перекодировкой в H.264.
